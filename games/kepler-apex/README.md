# Кеплер: Апекс

Самостоятельная 3D-гонка в стилистике «Кеплер: Дрейф»: ледяная орбита, бело-оранжевый болид, металлическая трасса и сдержанный приборный интерфейс.

Играть онлайн: [racing.moone.dev](https://racing.moone.dev). Публикация готовой сборки описана в [инструкции](../../docs/DEPLOYMENT.md).

Три круга по трассе длиной около 3,06 км, пять компьютерных соперников, торможение, форсаж, разгонные полосы и личные рекорды. Трасса, машины, планета и астероиды находятся в настоящей 3D-сцене.

## Запуск

Нужен Node.js 22.12+ или 24+. Проект самостоятелен: папка исходной игры для запуска не требуется.

```sh
npm ci
npm run dev
```

Откройте [http://127.0.0.1:5174/](http://127.0.0.1:5174/). Порт закреплён за этой игрой. Если он занят, Vite сообщит об этом, не переключаясь на другой адрес. На macOS можно запустить файл `Запустить игру.command`.

Открытие `index.html` двойным кликом не запускает приложение — нужен локальный сервер.

```sh
npm test
npm run build
npm run preview
```

Готовая сборка находится в `dist/`; предпросмотр — [http://127.0.0.1:4174/](http://127.0.0.1:4174/).

## Управление

| Действие | Клавиши |
| --- | --- |
| Повернуть | A / D или стрелки влево / вправо |
| Газ | W или стрелка вверх |
| Тормоз | S или стрелка вниз |
| Ручник / занос | Пробел + поворот |
| Форсаж | Удерживать Shift |
| Включить / выключить автогаз | G или кнопка «Автогаз» |
| Пауза | Esc / P |
| Управление | H |
| Звук | M |
| Полный экран | F |

Автогаз включён по умолчанию. Тормоз и ручник имеют приоритет над газом и форсажем. Для выхода из заноса отпустите пробел и контррулём выровняйте болид. На узком экране и сенсорных устройствах доступны отдельные кнопки поворота, тормоза и форсажа; они поддерживают несколько касаний одновременно.

## Правила

- Гонка начинается после отсчёта. Секундомер работает только во время заезда.
- Прохождение стартовой линии со стартовой решётки не засчитывается как круг. Для финиша нужно пройти три полных круга.
- Руль, курс кузова и боковая скорость меняются независимо. Сцепление ограничено: на высокой скорости шины срываются в скольжение, ручник облегчает занос. Перед крутым виражом снижайте скорость.
- Удары об отбойник отражают боковую скорость; сильный боковой удар тормозит заметнее касательного. Поворот кузова учитывается при контакте. Соперники обмениваются импульсом при столкновении.
- Форсаж расходует заряд; без форсажа заряд восстанавливается. После полного истощения нужно дождаться 25%.
- Голубые разгонные полосы дают 1,5 секунды разгона и восстанавливают 18% заряда при пересечении в нужной полосе.
- На финише показаны место, общее время и времена всех трёх кругов. Для ещё не финишировавших соперников указан оставшийся путь.
- Лучший завершённый заезд и лучший круг сохраняются локально в браузере. Запрет локального хранилища не мешает игре.
- Переключение вкладки или потеря фокуса автоматически ставит гонку на паузу. Возвращение в гонку требует нажатия «Продолжить».

## Устройство

TypeScript, Three.js, Vite и Lucide. Звук синтезируется через Web Audio после нажатия «На старт». Все ресурсы размещены локально; аккаунт и внешние API не нужны.

- `src/rules.ts` — движение, заряд, соперники, столкновения, круги и финиш.
- `src/track.ts`, `src/scenery.ts` — трасса и размещение астероидов с проверкой всего безопасного коридора.
- `src/physics.ts` — инерция, сцепление, занос и силы торможения.
- `src/motion-blur.ts`, `src/tire-trails.ts` — размытие движения и следы шин.
- `src/car.ts` — оригинальные модели болидов.
- `src/game.ts` — сцена, камера, управление и игровой цикл.
- `src/main.ts`, `src/style.css` — интерфейс, мини-карта и рекорды.
- `src/environment.ts`, `src/audio.ts` — орбита и звук.

Нужны WebGL 2 и аппаратное ускорение. Адаптивная компоновка не гарантирует производительность на каждом телефоне. Происхождение текстур и лицензии описаны в `ASSETS.md`.

## Проверки

Автоматические проверки охватывают паузу, отсчёт, торможение, предел скорости, истощение форсажа, пересечение ускорителей, отбойники, снос в повороте, подсчёт кругов, точное время финиша, порядок мест и сброс гонки. Сборка проверяет типы TypeScript.

При первоначальной проверке в Comet выполнен полный заезд из трёх кругов до экрана результатов (02:03.70), проверены сброс, пауза, ручной газ и сохранение рекорда. После доработки физики проверен новый полный заезд (01:30.71), видимое размытие на скорости и отсутствие ошибок WebGL.

22 автоматических теста проверяют в том числе 460 астероидов на четырёх наборах размещения, боковую инерцию, потерю сцепления, ручник, силу контакта, устойчивость интеграции и 810 вариантов портретного кадрирования с креном и заносом. Эмуляция размера не заменяет проверку на физическом телефоне.

## Ощущение движения

Motion blur рассчитывается по глубине 3D-сцены и движению камеры, усиливается на форсаже и выключается на паузе. Болид и приборы остаются читаемыми. Системная настройка уменьшения движения отключает размытие, расширение угла обзора и тряску камеры.

Кузов пружинит при разгоне и торможении, кренится в повороте; передние колёса поворачиваются, шины оставляют следы и звучат при скольжении. Это аркадная модель с помощью удержания направления трассы.
