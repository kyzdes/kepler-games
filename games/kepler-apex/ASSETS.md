# Происхождение ресурсов

## Визуальное направление

По запросу пользователя сохранена стилистика соседнего проекта `../kepler-drift` и выбранного для него концепта `../kepler-drift/concepts/01-orbital-realism.png`. Концепт не используется как фон или часть игровой сборки.

## Геометрия и эффекты

Болиды, колёса, антикрылья, трасса, ограждения, стартовые арки, полосы ускорения и астероиды построены процедурно в этом проекте. Звуки двигателя и событий синтезируются через Web Audio. Схема трассы рисуется по настоящим координатам контура.

Окружение `src/environment.ts` адаптировано из исходной игры: планета, кольца, звёздное поле и туманность. Освещение настроено для гоночной сцены. Исходные файлы игры «Кеплер: Дрейф» не редактировались.

## Текстуры

- `public/textures/kepler-ice.webp` скопирован из исходной игры вместе с `kepler-ice.webp.json`. Это созданная для неё встроенным imagegen карта ледяной планеты; точный исходный промпт и сведения о происхождении сохранены в метаданных.
- `public/textures/moon.jpg` скопирован из исходной игры без изменения содержимого и встроенных метаданных. Первичный источник — [официальный репозиторий Three.js](https://github.com/mrdoob/three.js/blob/dev/examples/textures/planets/moon_1024.jpg), лицензия MIT. В этой игре карта нанесена на процедурные астероиды.
