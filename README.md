# Kepler Games

[![Build and test](https://github.com/kyzdes/kepler-games/actions/workflows/ci.yml/badge.svg)](https://github.com/kyzdes/kepler-games/actions/workflows/ci.yml)

Две самостоятельные браузерные 3D-игры в общей космической стилистике. Three.js, TypeScript и Vite; процедурные модели, локальные текстуры и синтез звука через Web Audio.

| Игра | Что внутри | Играть | Исходники |
| --- | --- | --- | --- |
| **Кеплер: Дрейф** | Космический roguelike: астероиды, добыча руды, улучшения оружия, бочки и форсаж. Три сектора. | [asteroid.moone.dev](https://asteroid.moone.dev/) | [games/kepler-drift](games/kepler-drift/) |
| **Кеплер: Апекс** | Орбитальная гонка: три круга, пять соперников, заносы, ускорители и личные рекорды. | [racing.moone.dev](https://racing.moone.dev/) | [games/kepler-apex](games/kepler-apex/) |

## Запуск

Нужен Node.js 24 LTS с npm. Для игры — браузер с WebGL 2 и аппаратным ускорением.

```sh
git clone https://github.com/kyzdes/kepler-games.git
cd kepler-games
```

**Кеплер: Дрейф**

```sh
cd games/kepler-drift
npm ci
npm run dev
```

Открыть адрес, который покажет Vite: обычно [localhost:5173](http://localhost:5173/).

**Кеплер: Апекс**, в отдельном терминале из корня репозитория:

```sh
cd games/kepler-apex
npm ci
npm run dev
```

Открыть [localhost:5174](http://localhost:5174/). Игры независимы и могут работать одновременно. Открытие `index.html` с диска не заменяет запуск сервера.

## Управление

| | Дрейф | Апекс |
| --- | --- | --- |
| Движение | WASD / стрелки | A / D — руль, W — газ, S — тормоз |
| Форсаж | Shift: 6 секунд, скорость ×2,6 | Удерживать Shift, расходуется заряд |
| Манёвр | A / D + пробел — бочка | Пробел + поворот — ручник и занос |
| Дополнительно | ЛКМ — огонь, Q — автоогонь, U — оружейная за руду | G — автогаз |
| Общее | Esc / P — пауза, H — управление, M — звук, F — полный экран | Те же клавиши |

Автоогонь в «Дрейфе» и автогаз в «Апексе» включены при старте. Обе игры поддерживают сенсорное управление. Рекорды сохраняются в браузере; аккаунт не требуется.

## Проверки и сборка

В папке нужной игры:

```sh
npm test
npm run build
npm run preview
```

Готовый сайт находится в `dist/`. У каждой игры собственный `package-lock.json`. Автоматические проверки: 39 тестов «Дрейфа», 26 тестов «Апекса» и обе production-сборки. GitHub Actions повторяет тесты и сборку для каждой игры на push и pull request.

## Структура

```text
games/
  kepler-drift/     Космическая экспедиция
    src/           Игра, рендер, интерфейс, звук
    public/        Текстуры, шрифт, заставка

  kepler-apex/      Орбитальная гонка
```

## Ресурсы и лицензии

Корабль, болиды, трасса и астероиды строятся кодом. Карты планет, некоторые панорамы и заставка созданы с помощью генерации изображений; происхождение и промпты сохранены в проекте. Звуки синтезируются без загрузки внешних аудиофайлов.

Атрибуция: [ресурсы «Дрейфа»](games/kepler-drift/ASSETS.md), [ресурсы «Апекса»](games/kepler-apex/ASSETS.md), [лицензии библиотек и шрифта](third-party/README.md). Для оригинального кода и сгенерированных ассетов отдельная лицензия пока не задана.
