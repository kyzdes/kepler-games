# Публикация игр

Каждая игра собирается в самостоятельный статический сайт. Для работы опубликованной игры Node.js, база данных и серверный API не нужны.

Из корня репозитория:

```sh
npm --prefix games/kepler-drift ci
npm --prefix games/kepler-drift run build

npm --prefix games/kepler-apex ci
npm --prefix games/kepler-apex run build
```

Разместите содержимое `games/kepler-drift/dist/` и `games/kepler-apex/dist/` на двух отдельных сайтах или поддоменах. Каждый `dist` должен быть корнем соответствующего сайта: ресурсы игры используют абсолютные пути `/assets/`, `/textures/` и `/fonts/`.

Подходит обычная раздача статических файлов через Nginx или сервис статического хостинга. Включите HTTPS. HTML лучше отдавать с перепроверкой кеша, файлы с хешами в `/assets/` — с длительным кешированием. Текстуры и шрифт без хешей должны обновляться при новой публикации.

Для проверки сборки локально:

```sh
npm --prefix games/kepler-drift run preview
npm --prefix games/kepler-apex run preview
```

Запускайте эти команды в разных терминалах. Vite покажет адреса; у «Апекса» порт предпросмотра закреплён на 4174.

Для существующего VPS есть конфигурация «Дрейфа» в `games/kepler-drift/deploy/`: `compose.yaml` раздаёт `ASTEROID_RELEASE/dist` через Nginx и подключает домен asteroid.moone.dev к сети `dokploy-network`. Каталог выпуска содержит `dist/` и копию `deploy/`; `ASTEROID_RELEASE` указывает на его абсолютный путь. Для другого сервера настройте домен и внешнюю сеть. Другие способы статического размещения остаются доступны.

HTML на `/` и `/index.html` всегда возвращается полностью с `Cache-Control: no-cache`. Для него отключены ETag и проверка If-Modified-Since: у архивных выпусков могут совпасть размер файла и время модификации, хотя ссылки на новые JS/CSS уже другие. Ответ 304 в таком случае оставляет браузеру старое меню. Ресурсы с хешами в `/assets/` сохраняют долгий immutable-кеш. При создании архива также сохраняйте настоящее время модификации файлов.

Размещайте только production-сборку `dist/`: dev-диагностика из `tests/` в неё не входит. Текущие публичные версии доступны по ссылкам в основном README.
